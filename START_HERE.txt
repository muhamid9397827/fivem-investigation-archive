ابدأ من هنا
============

1) للتجربة السريعة:
   افتح ملف index.html في المتصفح.

2) الأفضل على ويندوز:
   افتح PowerShell داخل المجلد واكتب:
   python -m http.server 8080
   ثم افتح http://localhost:8080

3) النسخة الحالية تعمل بوضع تجريبي وتحفظ البيانات داخل المتصفح.

4) لتحويلها إلى موقع مشترك محمي:
   - أنشئ مشروع Supabase.
   - نفّذ ملف supabase/schema.sql.
   - عدّل config.js وضع demoMode: false.
   - أضف رابط Supabase ومفتاح anon.

5) للنشر على GitHub:
   ارفع المجلد كاملًا إلى مستودع، ثم فعّل GitHub Pages من GitHub Actions.
