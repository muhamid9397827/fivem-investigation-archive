# أرشيف التحقيقات القيادية — FiveM RP

موقع عربي لتنظيم ملفات الشخصيات القيادية والقضايا والتقارير والمرفقات داخل سيرفر FiveM Roleplay.

> المشروع مخصص للعب الأدوار فقط، وليس نظامًا أمنيًا أو قانونيًا حقيقيًا.

## النسخة الثانية

- إنشاء ملف أساسي لكل شخص وتعديله أو حذفه.
- فتح عدة قضايا داخل ملف الشخص، مع تعديل القضية أو حذفها.
- تقرير قضية جاهز ومنظم يشمل الملخص، الادعاءات، الإفادات، الإجراءات، النتائج، القرار والتوصيات.
- طباعة تقرير القضية مباشرة أو حفظه PDF من نافذة الطباعة.
- رفع الصور والفيديوهات والمستندات والملاحظات إلى القضية.
- تعديل وصف المرفق أو حذفه.
- قفل ملف الشخص برمز اختياري يختاره مدير الملف.
- وضع نهاري ووضع ليلي، مع حفظ الاختيار في المتصفح.
- تصميم عربي متجاوب مع الكمبيوتر والجوال.

## المشاركة الآمنة للقضايا

أضيفت صفحة مستقلة باسم `share.html` لعرض قضية واحدة فقط، دون الشريط الجانبي أو لوحة التحكم أو أي رابط إلى ملفات الأرشيف الأخرى.

يمكن لكل رابط أن يتضمن:

- تاريخ انتهاء.
- حد أقصى للمشاهدات.
- رمز دخول اختياري.
- إظهار أو إخفاء المرفقات.
- إظهار أو إخفاء أزرار التنزيل.
- إلغاء فوري من داخل القضية.

رمز المشاركة الخام لا يُحفظ في قاعدة البيانات؛ تُحفظ بصمته فقط، ويظهر الرابط الكامل مرة واحدة عند إنشائه.

## تفعيل المشاركة الحقيقية

المشاركة بين الأجهزة لا تعمل في `demoMode` لأن البيانات فيه محلية داخل المتصفح. لتفعيلها:

1. اربط الموقع بمشروع Supabase واجعل `demoMode: false` في `config.js`.
2. شغّل `supabase/migration_v3_secure_shares.sql` في SQL Editor.
3. انشر Edge Function الموجودة في `supabase/functions/case-share`:

```bash
supabase functions deploy case-share --no-verify-jwt
```

4. تأكد أن `config.js` يحتوي اسم الدالة `case-share`.

إخفاء زر التنزيل لا يمنع تصوير الشاشة أو حفظ وسائط يستطيع المتصفح عرضها، لكنه يمنع ظهور روابط تنزيل مباشرة للمستندات.
